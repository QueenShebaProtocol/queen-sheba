About Queen Sheba

Controlled Vulnerable AI Demonstration Website

Queen Sheba is an intentionally unshielded e-commerce demonstration environment. Its core purpose is to serve as a baseline target for cybersecurity testing and developing the AXF (AI Prompt Firewall) project.

Demonstration Scope Rule:

Queen Sheba intentionally does NOT contain prompt filtering, regex classifiers, or output scanners. All security controls belong to AXF.

Architecture: Baseline vs Protected

Current: User ➔ Queen Sheba Frontend ➔ Queen Sheba Backend ➔ LLM ➔ User
Future:  User ➔ [AXF Input Inspection] ➔ Backend ➔ LLM ➔ [AXF Output Inspection] ➔ User
