About Queen Sheba

Project Purpose & Architecture

Queen Sheba is an intentionally vulnerable AI application created for cybersecurity research and education. The application models a luxury Ethiopian-inspired electronic and lifestyle store with an AI customer support concierge.

The system is designed to provide a realistic, controlled demonstration environment for testing a separate project called AXF (AI Prompt Firewall).

Controlled Vulnerability Scope:

Queen Sheba contains no prompt firewall, no regex filters, no risk scoring, and no output sanitization. All defensive and classification layers belong strictly to AXF.

AXF Integration Architecture

Current (Vulnerable Baseline):
User ➔ Queen Sheba Frontend ➔ Queen Sheba Backend ➔ Queen AI / LLM ➔ Response ➔ User

Future Protected Flow (With AXF):
User ➔ [AXF Input Inspection] ➔ Queen Sheba Backend ➔ LLM ➔ [AXF Output Inspection] ➔ User

Fictional Demonstration Data Disclaimer

All products, order records (such as QS-1001, QS-1002), and demonstration credentials (e.g. DEMO_KEY_123456) are completely fictional. This system is never connected to real payment gateways or production databases.
